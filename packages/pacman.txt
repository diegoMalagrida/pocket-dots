# A line can name ALTERNATIVES, separated by `|`: `tealdeer|tldr`. If any of
# them is already installed the line is satisfied and nothing is added; only
# when none is does the first one go in. That is for pairs that cannot live
# together, where the one a machine already has is its owner's choice:
# Omarchy ships tldr, and asking for tealdeer there used to cancel the whole
# pacman transaction. (`jdk-openjdk|java-environment`: any JDK will do.)
#
# No kernel, bootloader or microcode here, on purpose. `linux`, `grub`,
# `os-prober` and `efibootmgr` used to be listed, which put a second kernel and
# its initramfs into /boot on CachyOS (linux-cachyos) or on an lts-only
# machine, and added a bootloader nobody asked for. Those are the choices you
# made when you installed Arch; the installer does not revisit them.
#
# python-dbus and python-gobject are needed by quickshell/scripts/bt-agent.py,
# which this repo installs AND enables as a service. They are listed here
# explicitly because nothing else asks for them: they used to be dragged in as
# a dependency of something else, and on 2026-09-10 an orphan cleanup took them
# away. Bluetooth pairing stopped working without a word -- `import gi` still
# got through, because at-spi2-core leaves a stray gi/overrides/ behind, and it
# only failed when asking for `gi.repository`.
